# Open Banking Labs Community

Welcome to the **Open Banking Labs** community discussions 👋

This repository is the source repository for Open Banking Labs organization-level Discussions. It is a public space for cross-repository and cross-product community conversations, including ideas, Q&A, announcements, and general collaboration.

> 💬 Join the organization Discussions:  
> https://github.com/orgs/open-banking-labs/discussions

This is **not** the DCC code repository. For DCC source code, issues, and releases, please use the DCC repository directly.

---

## What we are working on

Open Banking Labs explores open collaboration and practical work in the open banking space.

Currently, the organization has one main product:

### DCC

**DCC** is the current core product of Open Banking Labs.

- Repository: https://github.com/open-banking-labs/dcc
- Documentation: see the DCC repository README and docs
- Issue tracking: please use the DCC repository Issues for bug reports and concrete feature requests

For open-ended DCC discussions, questions, ideas, and community sharing, please use this community Discussions space.

---

## How to participate

Please choose the discussion category that best matches your topic:

| Category | Purpose |
| :--- | :--- |
| 📢 **Announcements** | Official announcements, releases, and community updates |
| 💡 **Ideas** | Feature suggestions, product ideas, and open banking proposals |
| 🙏 **Q&A** | Usage questions, clarifications, and troubleshooting with accepted answers |
| 🙌 **Show and tell** | Share integrations, experiments, examples, and practices built with Open Banking Labs or DCC |
| 🗳️ **Polls** | Quick community polls and preference gathering |
| 💬 **General** | Other general conversations |

Before posting, please:

1. Search for existing discussions that may already cover your topic.
2. Choose the most appropriate category.
3. Provide enough context, such as environment, version, steps already tried, and expected outcome.
4. Do **not** disclose security vulnerabilities publicly. Please follow `SECURITY.md`.

---

## Current scope

Open Banking Labs currently has only one product, **DCC**. As a result:

- DCC usage, integration, and defect-related issues should preferably go to the DCC repository Issues.
- Open-ended DCC discussions, ideas, Q&A, and community sharing are welcome in this repository’s Discussions.
- When additional products are added, this README and the discussion categories will be updated accordingly.
