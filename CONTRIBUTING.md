# Contributing to Open Banking Labs Community

Thank you for your interest in contributing to the Open Banking Labs community.

This repository is the source repository for Open Banking Labs organization-level Discussions. It is **not** the DCC code repository. Please use it for community discussions, questions, ideas, announcements, and general collaboration.

- DCC repository: https://github.com/open-banking-labs/dcc
- Organization Discussions: https://github.com/orgs/open-banking-labs/discussions

## What belongs here

This community space is appropriate for:

- Open-ended questions about Open Banking Labs or DCC
- Feature ideas and product suggestions
- Integration examples and community show-and-tell posts
- General community discussions
- Announcements and community updates

Please use the DCC repository Issues for:

- Reproducible bug reports
- Concrete feature requests that require tracking as work items
- Security vulnerabilities — **do not** report these publicly; see `SECURITY.md`

## Before you post

1. **Search first.** Check whether a similar discussion already exists.
2. **Choose the right category.** Use the category that best matches your topic.
3. **Provide context.** Include relevant versions, environment details, steps already tried, and expected outcomes.
4. **Be respectful.** Follow our [Code of Conduct](CODE_OF_CONDUCT.md).
5. **Do not disclose security vulnerabilities publicly.** Follow `SECURITY.md`.

## Discussion categories

| Category | Use for |
| :--- | :--- |
| 📢 Announcements | Official announcements, releases, and community updates |
| 💡 Ideas | Feature suggestions, product ideas, and proposals |
| 🙏 Q&A | Usage questions, clarifications, and troubleshooting |
| 🙌 Show and tell | Integrations, experiments, examples, and practices |
| 🗳️ Polls | Quick community polls |
| 💬 General | Other general conversations |

## Contribution to DCC

Code, documentation, and issue contributions for DCC should be made in the DCC repository:

https://github.com/open-banking-labs/dcc

Please follow the contribution guidance in that repository when submitting code or documentation changes.

## Community standards

By participating, you agree to follow:

- [Code of Conduct](CODE_OF_CONDUCT.md)
- [Security Policy](SECURITY.md)

## Questions

If you are unsure where to post, start a discussion in **General** and a maintainer will help route it.
