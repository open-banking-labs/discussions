# Security Policy

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub
Discussions, Issues, or pull requests.

If you believe you have found a security vulnerability in DCC or another
Open Banking Labs project, please report it privately using one of the
following channels:

1. **Preferred:** Use GitHub private vulnerability reporting for the affected
   repository, if enabled. For DCC, start here:
   https://github.com/open-banking-labs/dcc/security/advisories/new

2. **Alternative:** Contact the maintainers at:

   **[INSERT SECURITY CONTACT EMAIL]**

Please include as much of the following information as possible:

- A description of the vulnerability
- The affected repository, version, or component
- Steps to reproduce the issue
- Any potential impact you have identified
- Any suggested mitigation or fix, if available

## What to expect

The Open Banking Labs maintainers will:

- Acknowledge receipt of your report as soon as reasonably possible
- Investigate and validate the report
- Keep you informed of progress where appropriate
- Coordinate disclosure and credit with you if you wish to be credited

Please give us reasonable time to address the issue before any public
disclosure.

## Scope

This policy applies to Open Banking Labs repositories and projects, including:

- https://github.com/open-banking-labs/dcc
- Other repositories under https://github.com/open-banking-labs

This community Discussions repository is not intended for security reports.
Please do not disclose vulnerability details in Discussions.
